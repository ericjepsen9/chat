# ChatTrade（可注册、可持久化、可运行版）

这个版本不是前端 demo，而是**前后端一体的可运行版本**：

- 真实后端 API（Node.js）
- 用户可注册 / 登录
- 会话与消息保存在服务器 `data.json`（持久化）
- 首页为微信式“消息列表”
- 聊天功能全部收在 `+` 里，并带图标

## 启动

```bash
node server.js
```

浏览器打开：<http://localhost:4173>

## 默认账号

- alice / 1234
- bob / 1234

## 已实现能力

1. 注册/登录（真实后端校验）
2. 创建单聊/群聊
3. 文本消息、图片消息
4. 加号面板功能：表情、图片、@成员、商品卡、订单卡、钱包卡、商城卡
5. 群功能：公告、邀请成员、退群、静音
6. 卡片动作与订单状态流转
7. 消息列表搜索、未读计数

## 数据说明

- 服务器数据文件：`data.json`
- 重置数据：删除 `data.json` 后重启 `node server.js`
