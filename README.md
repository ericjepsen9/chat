# ChatTrade Mobile Web Prototype（完整版）

已实现**可用的完整聊天演示流程**（纯前端、浏览器本地存储）：

- 登录 / 创建用户 / 退出登录
- 单聊创建、群聊创建
- 会话列表（搜索、未读计数）
- 聊天消息：文本、表情、图片
- 群聊能力：@成员、群公告、邀请成员、退群、会话静音
- 聊天业务卡片：商品卡、订单卡（状态流转）、钱包卡、商城卡
- 订单状态流转：待付款 → 待发货 → 运输中 → 待收货 → 已完成

## 1. 启动

```bash
python -m http.server 4173
```

浏览器打开：<http://localhost:4173>

## 2. 默认账号

- alice / 1234
- bob / 1234

你也可以在登录页直接“创建用户”。

## 3. 测试建议流程

1. 使用 `alice` 登录。
2. 进入会话列表，打开单聊或群聊。
3. 发送文本、点击“🙂 表情”发送表情、点击“🖼 图片”发送图片。
4. 在群聊中点“@成员”，再发送消息。
5. 点右上角“⋯”测试群公告 / 邀请成员 / 退群 / 静音。
6. 使用快捷按钮发送商品卡，点击“下单”，继续推进订单卡状态。
7. 点击钱包卡/商城卡动作按钮，验证系统消息反馈。
8. 点底部“我”查看个人信息、创建测试用户、退出登录。

## 4. 数据说明

本项目无后端，所有用户、会话、消息数据都保存在浏览器 `localStorage`。
清空浏览器站点数据即可重置。
