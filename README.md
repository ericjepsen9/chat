# ChatTrade（修复版）

这个版本是前后端一体的可运行修复包，重点补上了：

- 基础鉴权（登录返回 token，后续接口走 Bearer Token）
- 密码哈希存储（新注册直接哈希；旧明文密码会在首次登录后自动迁移）
- 健康检查接口 `/api/health`
- 用户列表接口 `/api/users`
- 会话设置接口（免打扰 / 置顶 / 清空）
- 消息级删除 / 撤回接口
- 删除好友接口
- 请求体大小限制与非法 JSON 保护
- 静态资源路径收口
- 基础消息去重（`clientMessageId`）
- 基础 WAL 追加记录（审计用途）

## 启动

```bash
npm install
npm start
```

默认地址：

- http://127.0.0.1:4173
- http://localhost:4173

## 自测

```bash
npm test
```

会自动验证：

- 注册
- 登录
- 用户列表
- 加好友申请
- 创建会话
- 发消息与去重
- 拉消息
- 健康检查

## 注意

- 这是单机文件存储版本，适合演示与继续开发，不适合直接高并发生产。
- 升级后旧的本地登录缓存会失效，前端需要重新登录一次。
