# ChatTrade（可注册、可持久化、可运行版）

当前版本是可运行项目，不是纯前端 demo。

## 你问的两个问题

1. 聊天模块是否引入开源项目？
   - 当前聊天核心逻辑为本仓库自实现（前端 `app.js` + 后端 `server.js`）。
   - 浏览器侧通话依赖 WebRTC 标准 API（浏览器内置）。

2. 后端是否采用 Node.js？
   - 是的，后端是 Node.js 原生 `http` 服务（入口 `server.js`）。

## 当前已实现

- 登录 / 注册（后端真实校验）
- 消息页（会话列表 + 聊天页）
- 好友列表页（QQ式分组）
  - 添加好友
  - 分组查看
  - 右键好友可修改分组
- 单聊 / 群聊
- 文本 / 图片消息
- `+` 面板功能：表情、图片、@成员、商品卡、订单卡、钱包卡、商城卡、语音通话、视频通话
- 群功能：公告、邀请成员、退群、静音
- 订单卡状态流转
- 实时更新（SSE）
- 语音/视频通话（WebRTC 点对点，单聊场景）

## 启动

```bash
node server.js
```

浏览器打开：<http://localhost:4173>
