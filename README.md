# ChatTrade（高并发增强版 + 安装指南）

当前版本是可运行的前后端项目（Node.js 后端 + SPA 前端），并针对聊天高并发场景做了架构增强：

- 内存索引（用户/会话/消息/好友）减少全量扫描
- 异步批量落盘（write-behind）替代每次请求同步写文件
- 新增消息 WAL（`message.wal`）预写日志，降低进程异常时消息丢失风险
- SSE 按用户定向推送，避免全连接广播
- 新增健康检查接口：`/api/health`

> 说明：这版相比之前明显更抗压，但依然是单机 Node + 文件存储，不是最终分布式生产形态。进一步高并发建议升级到 MySQL/Redis/Kafka 架构。

---

## 安装方法（当前版本）

### 1) 环境要求

- Node.js 18+（建议 20+）

### 2) 安装与启动

```bash
# 进入项目
cd /workspace/chat

# 启动服务
npm start
# 或者
node server.js
```

启动后访问：

- <http://localhost:4173>

### 3) 默认账号

- alice / 1234
- bob / 1234

### 4) 运行测试

```bash
npm test
```

该命令会执行 `scripts/smoke-test.js`，自动完成：注册、登录、好友、会话、消息、健康检查。

### 5) 数据重置

- 数据文件：`data.json`
- 消息预写日志：`message.wal`
- 删除 `data.json` 与 `message.wal` 后重启服务即可重置。

> 通话提醒说明：Web 端可实现来电弹窗与自动跳转到通话页；但在浏览器后台/锁屏时提醒能力受系统与浏览器通知权限限制，移动端打包为安卓 App 后可获得更稳定的前后台来电提醒。

## 当前主要功能

- 注册 / 登录
- 消息列表、聊天页（未读消息按钮，已读自动消失）
- 好友列表（QQ式分组）
- 点击头像查看个人主页（备注名/签名/手机号/号码ID/发布商品）
- 单聊 / 群聊
- 文本 / 图片 / 卡片消息
- 首页加号菜单：扫一扫加好友 / 创建群聊 / 添加好友
- 聊天右上角消息设置：查找记录/静音/黑名单/删除好友/清空记录/会话置顶
- 订单卡流转
- SSE 实时更新
- 单聊语音/视频通话（WebRTC）
- 通话状态消息：通话时长 / 已取消 / 未接听
