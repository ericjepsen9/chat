# ChatTrade Mobile Web Prototype

根据 PRD（微信式聊天交易）实现了**手机端优先**的可运行网页版本，聚焦「聊天即交易」体验：

- 移动端 WeChat 风格 UI（顶部会话栏、聊天区、输入栏、底部 Tab）
- 聊天内业务卡片：商品卡、订单卡、钱包卡、商城商品卡
- 订单闭环状态流转：待付款 → 待发货 → 运输中 → 待收货 → 已完成
- 可直接在手机浏览器或移动端模拟器中运行

## Run

```bash
python -m http.server 4173
```

访问：<http://localhost:4173>

## 体验路径

1. 点击「商品卡片」发送商品。
2. 在商品卡片中点击「下单」，生成订单卡。
3. 按按钮推进订单状态，观察卡片在聊天中同步更新。
4. 点击「钱包卡片」体验聊天内收款 / 转账。
5. 点击「商城分享」体验 B2C 商品分享到聊天。
