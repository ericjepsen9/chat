# ChatTrade（WeChat 风格可运行版）

已按你的要求调整为：

- 首页就是**消息列表**。
- 进入消息页面后，不再显示“联系人/发现/我”等底部栏目。
- 聊天功能都折叠在输入框左侧 `+` 面板里（表情、图片、@成员、商品卡、订单卡、钱包卡、商城卡）。
- 支持登录/注册、创建单聊/群聊、群管理、业务卡片与订单状态流转。

## 运行

```bash
python -m http.server 4173
```

打开 <http://localhost:4173>

## 默认账号

- alice / 1234
- bob / 1234

## 关键可用功能

1. 登录后默认进入消息列表。
2. 点击会话进入聊天详情。
3. 点输入框左侧 `+` 展开全部聊天功能。
4. 右上角 `⋯`：
   - 在消息列表页：退出登录 / 创建测试用户
   - 在群聊页：群公告 / 邀请成员 / 退群 / 静音
5. 点消息页右上 `+` 可新建单聊或群聊。

## 数据存储

当前版本为纯前端可运行版本，数据保存在浏览器 `localStorage`。
清除站点数据后可重置。
