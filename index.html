ChatTrade 隐私保护政策

更新日期：2026年3月1日   生效日期：2026年3月10日

一、我们如何收集信息

为提供服务，我们将收集以下信息：

1. 注册信息：手机号码、昵称、登录账号、密码（加密存储）。

2. 个人资料：头像、个性签名等您主动填写的信息。

3. 通讯信息：聊天消息内容（用于消息传输和存储功能）。

4. 交易信息：商品发布信息、订单记录、收款方式等。

5. 设备信息：设备型号、操作系统版本、浏览器类型等基本信息。

6. 日志信息：访问时间、IP 地址（用于安全防护）。

二、我们如何使用信息

我们将收集的信息用于以下目的：

1. 提供即时通讯、商品交易等核心服务。

2. 身份验证和账号安全保护。

3. 改进和优化平台功能与用户体验。

4. 预防和处理欺诈、违规等安全风险。

5. 依法配合政府监管机构的要求。

三、信息的存储与保护

1. 您的个人信息存储在中国境内的安全服务器上。

2. 我们采用密码加密存储（scrypt 算法）、传输加密（HTTPS）等技术保护您的数据安全。

3. 我们会定期审查数据安全措施，持续改进安全防护能力。

4. 尽管我们采取了合理的安全措施，但请您理解互联网中不存在绝对的安全。

四、信息的共享与披露

除以下情形外，我们不会与第三方共享您的个人信息：

1. 经您明确同意后共享。

2. 为履行法律法规要求或配合政府部门调查。

3. 为保护本平台、用户或公众的权益和安全所必需。

4. 在平台发生合并、收购时，涉及个人信息转让将重新征得您的同意。

五、您的权利

您对您的个人信息享有以下权利：

1. 查看与修改：您可以随时在个人资料页查看和修改您的个人信息。

2. 删除：您可以删除您发布的内容（聊天记录、商品信息等）。

3. 账号注销：您可联系客服申请注销账号，我们将在合理时间内处理。

4. 撤回同意：您可以通过关闭相应功能撤回对部分信息收集的同意。

六、未成年人保护

本平台主要面向成年人提供服务。如果您是未满18周岁的未成年人，请在监护人指导下使用本平台。我们不会主动向未成年人推送商业信息。

七、Cookie 与本地存储

我们使用 localStorage 等浏览器本地存储技术保存您的登录状态和部分设置偏好，以提供更流畅的使用体验。您可以通过浏览器设置清除本地存储数据。

八、政策更新

我们可能根据法律法规变化或业务发展更新本政策。重大变更会通过平台公告或推送通知告知您。

九、联系我们

如您对本隐私政策有任何疑问或投诉建议，请通过平台内"意见反馈"功能与我们联系，我们将在15个工作日内答复。
