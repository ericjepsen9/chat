# 重写版技术栈

本文档记录项目重写时确定的技术栈及选型理由。

## 背景与约束

- 用户主要在中国大陆，服务器部署在境外
- 主打网页端，同时提供安卓 App 和 iOS App
- 登录以邮箱验证码为主，短信验证码为辅
- 需要端到端加密（E2EE）的聊天和通话

## 发布渠道

| 平台 | 方式 | 用户 |
|------|------|------|
| 网页 / PWA | 浏览器访问，可添加到主屏幕 | 所有用户，**iOS 大陆用户的主要方式** |
| 安卓 | APK 直接下载安装 | 国内外安卓用户 |
| iOS | App Store，**排除中国大陆区** | 海外和港澳台用户 |

iOS 不上架中国大陆区的原因：App 备案需要国内主体和接入商、即时通讯需要相关资质、国区应用不能使用 CallKit，且端到端加密聊天应用已有被国区下架的先例。

## 前端（网页和 App 共用一套代码）

| 部分 | 选择 |
|------|------|
| 语言 | TypeScript |
| 框架 | React + Vite |
| 路由 | React Router（SPA 模式） |
| 服务端数据 | TanStack Query |
| 客户端状态 | Zustand |
| UI | Tailwind CSS + Radix UI（shadcn/ui） |
| 数据校验 | Zod（前端和 Edge Functions 共用） |
| PWA | vite-plugin-pwa |
| 本地存储 | 网页用 IndexedDB（Dexie），App 用 SQLite，上层统一接口 |

## App 外壳（Capacitor）

| 部分 | iOS | 安卓 |
|------|-----|------|
| 前端资源 | **打包进 App，不远程加载** | 打包进 App |
| 热更新 | 只用于修 bug 和界面调整，WASM 跟随版本发布 | 同左 |
| 密钥存储 | Keychain | Keystore |
| 推送 | **APNs 直连** | 极光或个推（聚合厂商通道） |
| 来电（第二阶段） | CallKit + VoIP 推送 | 全屏通知 + 前台服务 |
| 原生通话（第二阶段） | Capacitor 插件封装 LiveKit iOS SDK | Capacitor 插件封装 LiveKit 安卓 SDK |

网页端在国内基本收不到推送（Chrome 推送依赖 FCM，国内浏览器普遍不支持），只能在页面打开时响铃。离线通知通过邮件补充。

## 加密

| 部分 | 选择 |
|------|------|
| 传输 | TLS（全站 HTTPS + HSTS） |
| 消息 E2EE | vodozemac（Olm 用于 1 对 1，Megolm 用于群聊），编译成 WASM，**打包在 App 内** |
| 备选方案 | MLS（OpenMLS WASM） |
| 文件加密 | AES-256-GCM（WebCrypto） |
| 密钥备份 | 恢复密钥，Argon2id 派生，加密后存服务器 |
| 身份验证 | 安全码 / 二维码核对，对方密钥变化时提醒 |
| 通话 E2EE | LiveKit E2EE，密钥通过加密聊天通道分发 |
| 运行方式 | 加密操作放在 Web Worker |
| 服务端敏感数据 | Supabase Vault，收款码放私有 bucket |

### E2EE 设计要点

- **不自己设计加密协议**。旧版 `app_crypto.js` 是简化实现，缺少前向保密、身份验证和多设备支持，不迁移到新项目
- 订单卡片、系统消息由服务器生成，**不走 E2EE**。数据表从一开始就区分"用户加密消息"和"系统消息"，消息内容存为不透明密文并带加密版本号
- 服务器无法搜索加密内容：聊天搜索在客户端本地进行
- 邮件离线通知不包含消息内容
- 用户丢失恢复密钥后，历史消息无法恢复，产品上需明确告知
- E2EE 只保护内容，不保护元数据（谁和谁、何时通信）。服务器应少存元数据并定期清理日志
- 网页端的代码由服务器下发，存在被篡改的风险；App 端代码经过签名，没有这个问题
- 上线前需做独立安全审查，审查通过前不对外宣传"端到端加密"

## 后端（Supabase）

| 部分 | 选择 |
|------|------|
| 部署 | Supabase 托管版，新加坡或东京（实测后定），自定义域名 |
| 数据库 | Postgres + RLS（所有权限在数据库层强制执行） |
| 登录 | 邮箱验证码为主，可选密码，短信辅助（绑定手机、找回账号） |
| 实时消息 | Realtime Broadcast 私有频道 |
| 文件 | Storage 私有 bucket + 签名 URL（存加密后的文件） |
| 业务逻辑 | Edge Functions：订单、通话令牌、推送、邮件通知、短信接入、账号注销 |
| 定时任务 | pg_cron：清理过期消息、元数据和日志 |
| 搜索 | 聊天内容在客户端本地搜；商品等非加密数据用 PGroonga |

注意事项：

- 前端不直接请求 `*.supabase.co`，统一走自己的域名，便于切换线路
- 实时消息用 Broadcast 频道，不直接监听 `messages` 表变更（群聊人数多时性能差）
- 跨境网络连接不稳定，前端必须做好断线重连和消息补拉

### 登录与验证码

- 使用 6 位数字验证码，不使用 Magic Link（在邮箱 App 内置浏览器打开会导致登录状态错位）
- 必须配置自定义 SMTP（Supabase 自带发信服务每小时只能发几封）
- 发信域名配置 SPF、DKIM、DMARC；邮件内容用中文、简短、不放链接
- 发送接口按 IP 和邮箱限流，并加人机验证
- 旧系统用户以手机号为用户名、没有邮箱：首次登录新系统时验证身份后强制绑定邮箱

## 通话

| 部分 | 选择 |
|------|------|
| 媒体服务器 | 自建 LiveKit（香港或日本），自带 TURN，支持 443 端口的 TURN/TLS |
| 令牌 | Edge Function 签发 |
| STUN | 不使用 Google STUN（国内无法访问） |

国内移动网络 NAT 严格，P2P 打洞经常失败，必须有 TURN 中继。

## 第三方服务

| 用途 | 选择 |
|------|------|
| 邮件（验证码 + 离线通知） | 阿里云邮件推送，SMTP 接入 |
| 短信（辅助） | 阿里云短信，Auth Hook 接入（签名通常需要企业资质） |
| iOS 推送 | APNs（Edge Function 直接发送） |
| 安卓推送 | 极光或个推 |
| 人机验证 | 阿里云验证码或 Cloudflare Turnstile，实测后定 |

## 部署和工程

| 部分 | 选择 |
|------|------|
| 服务器 | 两台香港或日本 VPS（带国内优化线路）：一台放前端和反向代理（Caddy），一台放 LiveKit |
| 仓库结构 | pnpm monorepo：`apps/web`、`packages/crypto`、`packages/shared`、`supabase/` |
| 测试 | Vitest、pgTAP（RLS 权限测试）、Playwright |
| 本地开发 | Supabase CLI |
| CI | GitHub Actions：检查、测试、构建 APK 和 iOS 包 |
| 代码规范 | ESLint + Prettier |

## 未采用的方案

| 方案 | 原因 |
|------|------|
| Expo（React Native） | Hermes 引擎不支持 WASM，加密代码需要为 iOS、安卓、网页分别接入；网页端包体积大 |
| Next.js | SSR 对海外服务器没有好处，增加运维复杂度 |
| 自研加密协议 | 容易出现安全缺陷，应使用经过验证的协议 |
| Magic Link 登录 | 在邮箱 App 内置浏览器中打开会导致登录状态错位，且更易进垃圾箱 |

## iOS 上架合规清单

- [ ] 前端资源打包进 App，不使用远程加载（`server.url`）
- [ ] 排除中国大陆区
- [ ] 举报、拉黑、用户协议（明确禁止违规内容）、公开联系方式
- [ ] App 内账号注销（真正删除数据）
- [ ] 隐私政策、隐私标签、隐私清单（PrivacyInfo.xcprivacy）、权限说明
- [ ] 加密出口合规申报（`ITSAppUsesNonExemptEncryption`）
- [ ] 后台模式（音频、VoIP）在审核时能演示
- [ ] 不在审核期间通过服务器开关隐藏功能
- [ ] 收款码只用于实物商品，审核备注里说明；虚拟商品必须用苹果内购

## 动工前需要验证的事项

以下任何一项不满足，都可能影响上述选型。建议开发前先做小型验证：

1. vodozemac WASM 在浏览器、WKWebView、安卓 WebView 中能否正常运行
2. Supabase 新加坡和东京从国内访问的延迟和稳定性（包括晚高峰）
3. 阿里云邮件发到 QQ、163 的到达率和延迟
4. LiveKit 在 WKWebView 和安卓 WebView 里的通话，包括开启 E2EE 后
5. 极光或个推在 Capacitor 安卓端的接入

## 风险提示

- 面向国内用户、服务器在境外的聊天服务可能被封锁，运营者也可能承担法律责任，投入前建议咨询律师
- 设备端风险无法通过加密消除：第三方输入法的云输入、浏览器扩展、木马、设备被检查。应提示用户关闭云输入，并提供阅后即焚功能
